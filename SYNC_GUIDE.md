# Repository Sync Guide

This project includes automated and manual workflows to keep `origin` (this repo) in sync with an optional `upstream` remote.

## Overview

| Method | Purpose | Location |
| ------ | ------- | -------- |
| GitHub Action | Scheduled + push-triggered fast-forward / merge | `.github/workflows/auto-sync.yml` |
| Manual PowerShell | Windows developer-initiated sync | `scripts/sync.ps1` |
| Manual POSIX Shell | Linux/macOS developer-initiated sync | `scripts/sync.sh` |

## GitHub Action: `auto-sync.yml`

- Runs hourly (minute 17) and on pushes to `master`/`main`.
- Adds `upstream` remote if `UPSTREAM_URL` secret exists.
- Attempts fast-forward; falls back to a no-edit merge for upstream divergence.
- Trivial conflict markers in doc-like files (`.md`, `.yml`, `.json`, `.toml`, `.txt`) may be auto-sanitized.
- Opens a fallback PR if a step fails (non fast-forward requiring manual review).

### Required / Optional Secrets

| Secret | Required | Description |
| ------ | -------- | ----------- |
| `SYNC_TOKEN` | Optional | PAT with `repo` scope (else GitHub token used) |
| `UPSTREAM_URL` | Optional | URL of upstream Git remote to mirror |

## Manual Sync (PowerShell)

```powershell
# Dry run
pwsh ./scripts/sync.ps1 -DryRun
# Real run (default branch master)
pwsh ./scripts/sync.ps1
# Custom branch / upstream
pwsh ./scripts/sync.ps1 -MainBranch main -Upstream upstream
```

## Manual Sync (POSIX)

```bash
# Dry run
DRY_RUN=true bash scripts/sync.sh
# Real run
bash scripts/sync.sh
# Custom
bash scripts/sync.sh main upstream
```

## Conflict Handling Strategy

1. Prefer fast-forward.
2. If FF fails, attempt standard merge.
3. Docs conflicts may be sanitized automatically in CI (very conservative).
4. Non-trivial conflicts require a human—action stops or PR is opened.

## Adding an Upstream Remote Locally

```bash
git remote add upstream https://github.com/ORG/REPO.git
git fetch upstream --prune
```

## Verifying Sync State

```bash
git fetch --all --prune
git log --oneline --graph --decorate --all --max-count=12
git remote -v
```

## Extending

- Adjust schedule cadence in `auto-sync.yml` under `on.schedule`.
- Add additional file patterns to auto-resolver cautiously.
- Integrate semantic merge tooling only after thorough testing.

## Troubleshooting

| Symptom | Resolution |
| ------- | ---------- |
| Workflow fails on FF merge | Inspect logs, check for upstream force-pushes |
| PAT permission denied | Regenerate PAT with `repo` scope |
| Endless trivial conflicts | Expand auto-sanitizer or rebase locally |
| Upstream not added | Ensure `UPSTREAM_URL` secret is set |
