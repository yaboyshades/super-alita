## Core Development Principles

- [ ] Code Quality Standards (ESLint/Prettier/Ruff configurations)

- [ ] Performance Benchmarks (API response < 200ms, Bundle size < 1MB)
- [ ] Security Guidelines (OWASP compliance, dependency scanning)
- [ ] Accessibility Standards (WCAG 2.1 AA compliance)

## Team Collaboration

- [ ] Code Review Requirements (2 approvals minimum)
- [ ] Documentation Standards

## Decision Framework

When faced with technical choices, prioritize:

1. User experience impact
2. System maintainability
3. Team development velocity
4. Technical debt implications
